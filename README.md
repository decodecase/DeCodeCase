# DecodeCase

A mobile and web application for solving interactive murder mystery cases.

## Project Overview

DecodeCase is a game where players step into the shoes of a detective to solve intriguing murder mysteries. Each case presents a unique story, complete with crime scene evidence, witness interrogations, and puzzles to unravel.

## Features (Planned)

*   Multiple unique cases
*   Interactive crime scenes
*   Evidence analysis
*   Witness interrogation system
*   In-app purchases for new cases
*   Cross-platform (iOS, Android, Web)
